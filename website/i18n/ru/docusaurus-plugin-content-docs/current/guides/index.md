# Руководства

Крейт `ruststream-sqlx` подключает базы данных SQL к сервису [RustStream](https://powersemmi.github.io/ruststream/latest/ru/) через [sqlx](https://docs.rs/sqlx).
Он состоит из двух частей.
Inbox - очередь задач в собственной таблице сервиса, которую крейт обслуживает как брокер RustStream.
Outbox хранит запись о каждом сообщении, которое сервис публикует через любой брокер RustStream, пока получатель его не обработает.
Обе части работают с Postgres, MySQL и MariaDB, а также с SQLite.
Руководства ведут сервис от первой очереди на SQLite через переобработку, порядок, транзакции и несколько экземпляров к промышленной среде на Postgres и показывают, как отслеживать его публикации в другие брокеры.
Начните с руководства [Начало работы](getting-started.md).
