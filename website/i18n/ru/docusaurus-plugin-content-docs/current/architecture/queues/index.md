# Таблицы

Очередь - это собственная таблица сервиса: строка - сообщение, группа - очередь, а роли столбцов
решают, когда строка готова к захвату и что делает исход.

<Diagram name="table" words={words} />

Крейт не создаёт таблиц и не выполняет миграций. `CREATE TABLE` пишет сервис, а структура
описывает таблицу для крейта: [`#[derive(Inbox)]`](api:ruststream_sqlx::Inbox) читает описание из
атрибутов, а [`InboxTable`](api:ruststream_sqlx::InboxTable) с
[`InboxSpec`](api:ruststream_sqlx::InboxSpec) - то же описание, написанное вручную. Каждую строку
пишет собственная реализация [`Publish`](api:ruststream_sqlx::Publish) сервиса, поэтому устройство
вставки тоже остаётся за сервисом.

Строка доступна для захвата при четырёх условиях, и каждое действует, только если в таблице есть
его столбец: строка входит в группу подписки, её `retry_after` прошёл, её `processed_at` пуст, и её
не держит аренда (`locked_until` пуст или прошёл). Захват берёт доступные строки в порядке
захвата: сначала `priority`, меньшее значение раньше, затем `retry_after`, затем id. Строка с
`retry_after` в будущем - отложенная задача: очередь не видит её, пока не придёт её время.

Имя подписки выбирает её очередь. В таблице со столбцом `group` это группа, и каждая группа -
отдельная очередь. В таблице без этого столбца имя обозначает всю таблицу. Один брокер открывает
одну подписку на очередь: вторая подписка на ту же таблицу и группу останавливает сервис при
старте с ошибкой
[`SqlxBrokerError::AlreadySubscribed`](api:ruststream_sqlx::SqlxBrokerError::AlreadySubscribed).
Несколько брокеров или несколько экземпляров сервиса делят одну очередь, а форма захвата разводит
их строки.

То, что строка передаёт обработчику, зависит от двух ролей. Со столбцом `payload` строка в режиме
полезной нагрузки: обработчик принимает полезную нагрузку, декодированную кодеком. Без него строка
в режиме строки: обработчик принимает саму строку в том виде, в каком её прочитал драйвер. Столбец
`headers` хранит заголовки доставки в одном столбце: при фиче `json` это объект JSON со
строковыми значениями. Раскладка заголовков по столбцам читает их вместо этого из отдельных
столбцов, по столбцу на заголовок. Таблица без того и другого доставляет пустые заголовки.

«Сейчас» читается, когда захват выбирает готовые строки, когда переобработка откладывает строку и
когда ack её отмечает. По умолчанию его читает хост, через
[`SystemClock`](api:ruststream_sqlx::SystemClock), и передаёт в собственном типе столбца. При
`clock = DatabaseClock` операторы вместо этого читают часы базы данных:

| База данных | «Сейчас» в операторе |
|---|---|
| PostgreSQL | `statement_timestamp()` |
| MySQL, MariaDB | `UTC_TIMESTAMP(6)` |
| SQLite | `strftime('%Y-%m-%dT%H:%M:%f+00:00', 'now')`, текст |

SQLite хранит время как текст и сравнивает его как текст, поэтому таблица там держит один формат
времени во всех строках. Форма аренды всегда читает часы хоста: таблица аренды на `DatabaseClock`
не компилируется по причине, которую называет страница [Захват](claims.md).

Как захват берёт строку в работу, описывает страница [Захват](claims.md), а что записывает каждый
исход - страница [Завершение](../settlement.md).
